## งานที่ยังค้าง / จุดสำคัญให้ Claude ตรวจ

1. **พิกัดแม่เหล็กกำลังแก้ไม่ครบ**
   - `work/config.js` เปลี่ยน `magnet.y` จาก 21 เป็น 1 เพื่อจะใช้เป็น offset จาก `boardY`
   - แต่ `work/model.js` ยังใช้ `Math.min(q.y, ...)` เป็นพิกัดสัมบูรณ์ จึงวางที่ Y=1 ซึ่งอาจชนแบต
   - ต้องเปลี่ยนให้ใช้ `p.boardY + q.y` และปรับแผ่นเสื้อ/ป้าย/ตำแหน่งที่เกี่ยวข้องให้ตรงกัน
   - HTML รุ่นที่รวมแล้วใช้ y=21 เดิม ซึ่งพบการซ้อนกับตัว USB บนบอร์ดบางส่วน ต้องแก้ทั้ง source และ rebuild

2. **สายแพกล้องยังพาดผ่านพื้นที่ซ็อกเก็ต microSD**
   - ต้องจัดเส้นทางอ้อมขอบซ็อกเก็ตก่อนลดระดับลงหาจุดต่อ
   - ตรวจไม่ให้ไปบังรู/ท่อไมค์ ทางดันการ์ด หรือกินพื้นที่ฝาปิด
   - ความยาวและรัศมีดัดสายแพต้องวัดของจริง

3. **ป้ายชื่อและ responsive ยังต้องตรวจหลังรวมล่าสุด**
   - โค้ดจัดป้ายใหม่ยังไม่ได้ดูภาพจริง
   - ตรวจจอแคบ, การสลับแบต/ชุดยึด, มุมกล้อง และลำตัว

4. **STL เป็นหลาย solid ที่มีส่วนซ้อนกัน**
   - ผิวกล่องหลักเป็นผิวปิด และ primitive แต่ละชิ้นผ่าน topology test
   - เสารอง หูยึด และบางส่วนยังประกอบด้วย solid ซ้อนกัน ไม่ได้ Boolean union
   - UI แจ้งให้ใช้ Union ใน slicer แล้ว ยังไม่ควรอ้างว่าเป็น watertight unified solid พร้อมพิมพ์

5. **microSD เข้าถึงแบบชั่วคราว**
   - ขอบการ์ดอยู่ลึกจากผนังด้านในประมาณ 7 มม. / 11.5 มม. ตามขนาดแบต
   - ช่องสูง 3.5 มม. อาจกดหรือดึงด้วยนิ้วไม่ได้ ต้องตรวจแกนเสียบจริงหรือออกแบบช่อง service ใหม่

6. **USB-C ด้านล่างเป็นแนวคิดต่อสายเพื่อชาร์จ**
   - บอร์ดอยู่ด้านบน จึงไม่ได้อ้างว่า USB บนบอร์ดตรงช่องล่างโดยตรง
   - ระบบชาร์จ การต่อสาย การยึดพอร์ตและ strain relief ยังไม่ใช่วงจรที่ตรวจรับรองแล้ว

7. **ความครบของ CONFIG**
   - มีค่าหลักรวมไว้แล้ว แต่ยังควรตรวจค่าขนาด/ระยะที่ฝังใน model.js/app.js และย้ายค่ากายภาพที่เหลือเข้า CONFIG ให้ครบตามคำขอ

## ลำดับทำต่อที่เสนอ
