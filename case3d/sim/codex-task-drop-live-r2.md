# งาน Codex: หน้าเว็บจำลองการตก รอบ 2 — เทียบแบบเก่า (ห่วงยื่น) กับแบบใหม่ (แผ่นหัว + แท่งเกี่ยว)

ต่อจาก `sim/codex-task-drop-live.md` ซึ่งเสร็จแล้วและเทสต์ผ่าน 5/5 ห้ามทำให้สิ่งที่มีอยู่พัง

## Claude เตรียมไว้แล้ว
- **STL แยกโฟลเดอร์ตามแบบ ใช้อันนี้แทน `../print/v2`:**
  - `sim/designs/eyelet/`: แบบเก่า ห่วงยื่น (เป็นชุดที่ส่งร้านพิมพ์จริงแล้ว) ฝาหลังใช้ `model = (x, y + 3.25, z − 10.75)`
  - `sim/designs/lug/`: แบบใหม่ Rev 3 ฝาหลังใช้ `model = (x, y + 3.5, z − 10.75)` เพราะ export จัดกึ่งกลางกรอบใหม่ที่ยาว 105 มม.
  - ฝาหน้าของทั้งสองแบบเหมือนกันทุก byte และใช้ `model = (x, −y, 10.75 − z)`
- **ผล FE คำนวณใหม่ด้วยวิธีเดียวกันทั้งสองแบบ:**
  - เช็กเนื้อทีละก้อนแล้วรวม เพราะ STL มีหลายก้อนซ้อนกัน
  - สัมผัสแบบเส้นกระจายแรงตามความยาวเส้น
  - `sim/drop-fe-results.json`: แบบ eyelet มี eyelet-top, eyelet-diag, corner-back, corner-front, rim-side
  - `sim/drop-fe-results-lug.json`: แบบ lug มี tab-top, tab-corner, tab-edge, corner-back, corner-front, rim-side
- **ทุกแถวมี `part`, `R`, `L`, `backOffsetY` แล้ว:** ให้ `drop-model.mjs` อ่านค่าจากแถวก่อน แล้วค่อย fallback ไปที่ `CASE_CONTACT` เดิม จะได้ไม่ต้องแก้โค้ดทุกครั้งที่เพิ่มจุดชน
- `drop-fe-results.v1-before-union.json` เป็นของเก่า ไม่ต้องใช้

## เรขาคณิตสำหรับ `classify` ของแบบ lug (หน่วยมม. พิกัดโมเดล เทียบจุดศูนย์ถ่วงที่ z −2.5 เหมือนเดิม)
- **support function ของปริซึมสี่เหลี่ยมมุมมน:** ศูนย์กลาง (cx, cy) ครึ่งความกว้าง/สูง (hx, hy) มุมโค้ง r และช่วง z [z0, z1]
  `h(d) = cx·dx + cy·dy + (hx−r)|dx| + (hy−r)|dy| + r·hypot(dx,dy) + max(z0·dz, z1·dz)`
- **ตัวกล่อง:** cx 0, cy 0, hx 20, hy 49, r 5, z [−10.75, 10.75]
- **แผ่นหัว:** cx 0, cy 51.75, hx 20, hy 4.25, r 3, z [−10.75, 0]
  - ยื่นเฉพาะฝั่ง y+ ส่วนมุมล่างของแผ่นหัวจมอยู่ในกล่อง ใช้ r เดียวกันได้
- **กติกาตัดสิน (ให้ใช้ z ที่เทียบ COM แล้วเหมือน `classify` เดิม):**
  - ถ้า `h_tab > h_box + 0.05` แสดงว่าแผ่นหัวแตะพื้นก่อน ให้แบ่งต่อเป็น 3 แบบ
    - `|dx|/hypot(dx,dy) < sin 6°` คือ `tab-top`
    - `|dz| < sin 6°` คือ `tab-edge`
    - นอกนั้นคือ `tab-corner`
  - ถ้าไม่ใช่ ให้ใช้กติกา มุม / ขอบ / หน้า เดิม
- **ส่วนแบบ eyelet** ให้ใช้ `classify` เดิมทุกอย่าง

## สิ่งที่ต้องทำ
1. **`drop-designs.json`:** มี 2 แบบ
   - **`eyelet`:** ชื่อ "แบบเก่า · ห่วงยื่น (ส่งพิมพ์แล้ว)"
   - **`lug`:** ชื่อ "แบบใหม่ · แผ่นหัว + แท่งเกี่ยว (Rev 3)"
   - **ระบุในแต่ละแบบ:**
     - ไฟล์ STL
     - ไฟล์ FE
     - `backOffsetY`
     - `shape`: `eyelet` หรือ `lug`
     - การแมปจุดแตะพื้นไปยังจุดชนใน FE
       - **eyelet:** ห่วงตรงลง ไป eyelet-top, ห่วงเฉียง ไป eyelet-diag
       - **lug:** tab-top / tab-corner / tab-edge ไปจุดชนชื่อเดียวกัน
       - **ทั้งสองแบบ:** มุมฝาหลังหรือฝาหน้าไป corner-back/front, ขอบไป rim-side, หน้าราบใช้ค่าประมาณ
2. **`build-drop-live.mjs`:** อ่านไฟล์ FE แยกตามแบบ ห้ามใช้ไฟล์เดียวร่วมกัน และใช้ `backOffsetY` ของแต่ละแบบตอนแปลงพิกัด STL ในหน้า ห้ามเขียน 3.25 ตายตัว
3. **หน้าเว็บ:** เอาโค้ดที่ผูกกับห่วงไว้ตายตัวออกทั้งหมด ได้แก่ `featureFor`, `selectedCase`, `batch` และตัวเลือกท่า "ห่วงลง"
   - **ท่าตก:** เปลี่ยน "ห่วงลง" เป็น "หัวลง (ห่วง/แผ่นหัว)" แล้วตั้งท่าให้จุดบนสุดของแบบนั้นชี้ลง
     - แบบ eyelet: ห่วงเอียงเล็กน้อยให้ห่วงแตะก่อน
     - แบบ lug: เอียงเล็กน้อยตามแกน x ให้ขอบแผ่นหัวแตะก่อน
   - **ป้ายส่วนที่แตะพื้นก่อน (ภาษาไทย):** "ห่วงตะขอ", "แผ่นหัว (สัน)", "แผ่นหัว (มุม)", "แผ่นหัว (ขอบเฉียง)", "มุม", "ขอบ", "หน้าราบ"
   - **การสุ่ม 1,000 ครั้ง:**
     - สุ่มตามแบบที่เลือก
     - เพิ่มปุ่ม "เทียบสองแบบ" สุ่มชุดเดียวกัน (seed เดียวกัน ใช้ PRNG ที่กำหนด seed ได้) แล้วแสดงกราฟสองแบบข้างกัน หรือเรียงบนล่างเมื่อจอ < 700 px
     - กราฟแสดง % ระดับความเสียหาย และ % ส่วนที่แตะพื้นก่อน
   - **ค่าเริ่มต้นเมื่อเปิดหน้า:** แบบ `eyelet`
   - **กล่องสรุปสั้นๆ ด้านบน** สร้างจากผลสุ่มเทียบสองแบบตอนโหลดหน้า เช่น "ตกจาก 1.3 ม. PLA: แบบเก่าร้าว X% → แบบใหม่ Y%"
4. **หมายเหตุใต้แผงผลเมื่อจุดชนเป็น rim-side:** "ค่าขอบข้างน่าจะสูงเกินจริง: FE คิดฝาหลังชิ้นเดียว ขอบที่รอยต่อฝาจึงลอยอิสระ ของจริงมีฝาหน้าและสกรูช่วยยึด"
5. **`test-drop-live.mjs`:** ขยายเทสต์
   - **ข้อ 1:** ทำกับทั้งสองแบบ ทุกจุดชนในไฟล์ FE ต้องต่างไม่เกิน 5%
   - **ข้อ 2:** แบบ eyelet เหมือนเดิม ส่วนแบบ lug เทียบ `classify` กับวิธี brute force
     - สุ่มทิศ 20,000 ทิศ
     - หาจุดต่ำสุดจากจุดยอดของ STL ทั้งสองฝาของ lug ในพิกัดโมเดล
     - แบ่งกลุ่มตามตำแหน่ง: y > 49.3 คือแผ่นหัว นอกนั้นใช้กติกาเดิม
     - สัดส่วน แผ่นหัว / มุม / ขอบ / หน้า ต่างกันไม่เกิน ±3%
   - **ข้อ 5 (Edge):** ทำทั้งสองแบบ
     - แบบ eyelet + หัวลง + PLA 1.3 ม. ต้องได้ "ร้าว"
     - แบบ lug + หัวลง + PLA 1.3 ม. ต้องไม่ใช่ "ร้าว"
     - กด "เทียบสองแบบ" แล้วต้องมีกราฟ 2 ชุด
     - console ต้องไม่มี error
     - บันทึกภาพไว้ที่ `sim/check-drop-live.png` (อยู่ใน `sim/` ทำได้) และ `sim/check-drop-live-compare.png`
6. **build ใหม่:** สร้าง `drop-live.html` ใหม่ ต้องไม่เกิน 3 MB
