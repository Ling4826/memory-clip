# งาน Codex: ย้ายรูไมค์ให้ตรงตำแหน่งที่วัดจริง

ต่อจาก r4 ห้ามทำให้สิ่งที่ทำไว้พัง (ค่าที่วัด, กล้อง, การ์ด SD, ฝาหน้าปิดสนิท, รูตะขอ Ø4.0, โหมดแอนิเมชัน) Claude สำรองไฟล์ไว้แล้ว

## ค่าที่วัด (เวอร์เนียร์ 23 ต.ค.)
- **รูเสียงไมค์:** เป็นรูขอบทองเล็กๆ บนตัวไมค์ MEMS (ชิ้นสีดำประมาณ 3.3 × 2.5 มม.) ที่ติดอยู่บนบอร์ด Sense ด้านเดียวกับกล้อง เป็นไมค์รับเสียงทางด้านบน ไม่ใช่รูทะลุ PCB
- **มองด้านกล้องให้ขั้วต่อสายแพสีขาวกับ USB อยู่ด้านล่าง:**
  - กลางรูห่างขอบล่าง (ฝั่ง USB) **7.4 มม.**
  - กลางรูห่างขอบซ้าย (ฝั่งที่มีขา **D11**) **1.0 มม.**
- **แปลงเป็นพิกัด:** ใช้ตำแหน่งขา D11 ใน model เป็นตัวบอกว่าฝั่งซ้ายคือ x+ หรือ x− ห้ามเดาเครื่องหมาย
  - model ตอนนี้ไม่มีขา D11 ให้ใช้เครื่องหมายเดียวกับค่าเดิม (x−) เพราะค่าเดิมก็ประมาณจากรูปว่าอยู่ฝั่งซ้ายเหมือนกัน
  - บอกในรายงานว่าใช้วิธีนี้
  - เก็บภาพหน้าจอมุมมองด้านกล้องที่เห็นรูไมค์และกล้องชัดเจนไว้ที่ `case3d/check-mic.png` ให้ Claude เอาไปเทียบกับรูปบอร์ดจริง
  - ใน config ที่กลาง PCB = (0,0) และ USB อยู่ y− ได้ `y = 7.4 − 10.5 = −3.1`
  - `|x| = 8.9 − 1.0 = 7.9` บอร์ดกว้าง 17.8
  - ค่าเดิม `x −6.8, y −8.5` ต่างจากที่วัดได้ในแนว y ประมาณ 5.4 มม.

## สิ่งที่ต้องแก้
1. **แก้ค่าใน CONFIG:** แก้ `detail.sense.mic` หรือที่ที่เก็บตำแหน่งไมค์อยู่ ให้ตรงค่าที่วัด พร้อมคอมเมนต์ "วัดเวอร์เนียร์ 23 ต.ค." และวิธีแปลงพิกัด
2. **ย้ายรูไมค์และท่อไมค์บนฝาหน้า:** ให้แนวกลางตรงกับรูเสียงที่ตำแหน่งใหม่
   - **ระยะชิดขอบ:** รูอยู่ห่างขอบบอร์ดแค่ 1 มม. ให้ตรวจว่ารูหรือท่อไม่ชนผนังข้างกล่อง เสา หรือสกรู
   - **ถ้าชน:** ให้เลื่อนรูทั้งชุด หรือลดจำนวนรู โดยให้มีรูอย่างน้อย 1 รูอยู่ห่างกลางรูเสียงไม่เกิน 1.5 มม.
   - **ความหนาผนัง:** ผนังทุกจุดยังต้องหนาอย่างน้อย 1.2 มม.
3. **เพิ่มเทสต์:** วัดระยะในแนวระนาบ (XY) จากกลางรูเสียงไมค์ถึงรูบนฝาหน้าที่ใกล้ที่สุด ต้องไม่เกิน 1.5 มม.
4. **Export ใหม่:** เฉพาะชุดคล้องคอ 4 ไฟล์ไปที่ `print/v2/` แล้วอัปเดต manifest และ handout

## รายงานภาษาไทยสั้นๆ
- ไฟล์ที่แก้
- ตำแหน่งไมค์ค่าเดิมและค่าใหม่ บอกเครื่องหมาย x ที่ได้จาก D11
- ระยะจากรูเสียงไมค์ถึงรูบนฝาหน้าที่ใกล้ที่สุด
- ผล `verify.mjs`

## การเขียนไฟล์
- **เขียนไฟล์เป็น UTF-8 เสมอ:** รอบ r3 คอมเมนต์และข้อความภาษาไทยใน `config.js` เพี้ยนเป็นภาษาต่างดาว (UTF-8 ถูกอ่านเป็น cp874) Claude ซ่อมแล้ว
- **ห้ามใช้ `Set-Content`/`Get-Content` ของ PowerShell แก้ไฟล์:** ถ้าไม่ระบุ encoding จะเพี้ยนแบบเดิม ให้ใช้ apply_patch หรือ Node `fs` กับ `'utf8'`
- **ตรวจก่อนจบงาน:** หลังแก้ ให้ค้นไฟล์ที่แก้ว่าไม่มีลำดับอักขระ `เธ` ที่ไม่ใช่คำไทยจริง เช่น `เธฃเธ`
