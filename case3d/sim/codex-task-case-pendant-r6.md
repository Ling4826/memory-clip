# งาน Codex: เปลี่ยนห่วงตะขอที่ยื่นออกนอกกล่องเป็น "แท่งเกี่ยว" ในแผ่นหัวกล่อง (ฝาหลังเท่านั้น)

ต่อจากงาน r2–r5 ที่เสร็จแล้ว ห้ามทำให้สิ่งที่ทำไว้พัง ได้แก่
- ค่าที่วัดแล้ว
- ตำแหน่งกล้อง การ์ด SD และรูไมค์
- ฝาหน้าที่ปิดสนิท
- ด้านหลังที่เรียบแล้ว (`rearPad.depth = 0`)
- โหมดแอนิเมชันการห้อยคอ
- ชิ้นทดสอบขนาดแบบ 3 แถว

Claude สำรองไฟล์ไว้แล้วที่ `_backup/case3d_before_r6_20261023/` ไม่ต้องทำซ้ำ

## ทำไมต้องแก้
ผลจำลองการตก (`sim/drop_fe.py`, `sim/drop-fe-results.json`) บอกว่า
- **ห่วงตะขอยื่นออกนอกกล่อง** ทำให้ห่วงเป็นจุดแรกที่ชนพื้นถึง 34% ของการตกแบบสุ่ม
- **โคนห่วงที่ต่อกับขอบกล่องเป็นมุมหักฉาก** ความเค้นที่โคนประมาณ 0.2 MPa ต่อแรง 1 N ตกจาก 1.3 ม. จะเกินกำลัง PLA ประมาณ 3.5 เท่า
- **มุมกล่องปกติแค่บุบ ไม่ร้าว** (อัตราส่วนความเค้นต่อกำลังประมาณ 0.5)

## แบบใหม่: แผ่นหัวกล่อง (lanyard tab) บนฝาหลัง
- **เอาออก:** ห่วงวงแหวน 2 อันที่ยื่นออกนอกกล่อง (`pendant-lanyard-eyelet`)
- **ใส่แผ่นหัวกล่องที่ปลายบน (ฝั่ง y+):**
  - ทำเป็นเนื้อเดียวกับฝาหลัง กว้างเท่ากล่อง 40 มม. ยื่นเลยขอบบนของกล่องเดิมออกไป `tabLength ≈ 7 มม.`
  - มุมโค้ง R5 ให้ต่อกับมุมกล่องเดิม
  - ความหนาตามแกน z เท่ากับฝาหลัง คือจากผิวหลังถึงระนาบรอยต่อฝา ฝาหน้าไม่ต้องแก้ ฝาหน้าจะสั้นกว่าฝาหลังตรงหัวกล่อง
- **ช่องทะลุ 2 ช่องตามแกน z ในแผ่นหัว:**
  - กลางช่องอยู่ที่ x = ±14 ขนาดช่องประมาณ 7 (x) × 4.5 (y) มม. มุมในช่องโค้ง R1
  - ผนังระหว่างช่องกับขอบข้างกล่องหนาอย่างน้อย 1.6 มม.
- **แท่งเกี่ยว (bar):** คือเนื้อระหว่างช่องกับขอบบนของแผ่นหัว ตะขอจะเกี่ยวรอบแท่งนี้
  - กว้าง (y) 3.0 มม. ต้องอยู่ระหว่าง 1.6 ถึง `hookGate − 0.8` (3.7) ตะขอถึงจะอ้อมแท่งแล้วปิดก้านได้
  - หนา (z) ไม่เกิน 5 มม. ตะขอถึงจะคล้องรอบแท่งได้ ช่องในตะขอประมาณ 9 × 14 มม. เป็นค่าประมาณจากรูป รอวัดจริง ถ้าแผ่นหัวหนากว่า 5 มม. ให้เว้าเนื้อด้านหน้าของแท่ง (ฝั่ง z+) ออก ให้เหลือแท่งหนา 5 มม.
  - ผิวนอกของแท่งต้องเว้าลึกจากขอบบนของแผ่นหัว 0.8 มม. ตลอดช่วงแท่งและเลยออกไปข้างละ 1 มม. ถ้าตกเอาหัวลง ส่วนข้างๆ แท่งจะชนพื้นก่อน
- **ช่องต้องใหญ่พอให้ปลายตะขอลอดได้:** ด้านที่แคบที่สุดของช่องต้อง ≥ `hookWire + 1.3` (4.0 มม.)
- **ห้ามชน:** เสาสกรูมุมบน (x ±16, y 45) บอร์ด กล้อง และฝาหน้า
- **ทิศพิมพ์ยังเหมือนเดิม:** วางผิวหลังลงฐาน ช่องทะลุแนวตั้ง จึงไม่มีส่วนที่ต้องพิมพ์ลอย

## CONFIG และเทสต์
- **CONFIG:** เพิ่ม `pendant.lug` เก็บ `tabLength`, `slot`, `slotX`, `slotRadius`, `barWidth`, `barDepth`, `barRecess` พร้อมคอมเมนต์ภาษาไทย แล้วปิดหรือลบ `pendant.eyes` ออกจากแบบคล้องคอ ถ้ามีโค้ดอื่นยังใช้ `eyes` อยู่ ให้แก้ตาม
- **เทสต์ใหม่หรือแก้เทสต์ใน `test-print.mjs` / `test-v2.mjs`:** ตรวจจาก CONFIG
  - `1.6 ≤ barWidth ≤ hookGate − 0.8`
  - ด้านแคบของช่อง ≥ `hookWire + 1.3`
  - ผนังข้างช่อง ≥ 1.6
  - `barDepth ≤ 5`
  - แท่งเว้าลึกจากขอบบน ≥ 0.8
  - ไม่มีชิ้นส่วนอื่นยื่นออกนอกแนวกล่องรวมแผ่นหัว (ไม่มีห่วงยื่นแล้ว)
  - ฝาหลังยังปิดสนิท
- **เทสต์เดิม:** ที่ตรวจห่วงวงแหวนให้เปลี่ยนไปตรวจแท่งเกี่ยวแทน ห้ามลบเทสต์ทิ้ง
- **ข้อมูลจำลองการแกว่ง:** `sim/pendant-sim.mjs` กับ `pendant-clips.json` ไม่ต้องแก้ แต่ให้เขียนไว้ใน handout ว่าจุดเกี่ยวย้ายจาก x ±18 เป็น ±14

## Export และเอกสาร
- **Export:** เฉพาะชุดคล้องคอ 4 ไฟล์ไปที่ `print/v2/` แล้วอัปเดต manifest, README และ handout

- **รันตามลำดับจาก `case3d/`:**

  2. `node work/render-print.mjs`
  3. `node work/build-print-handout.mjs`
