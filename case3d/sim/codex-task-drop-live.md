# งาน Codex: หน้าเว็บจำลองกล่องตกแบบสด (live)

## เป้าหมาย
ทำหน้าเว็บแยกต่างหากให้ผู้ใช้กดปล่อยกล่องให้ตกพื้นได้เอง ดูท่าตกแบบ 3D เห็นว่าส่วนไหนแตะพื้นก่อน แล้วบอกว่าเสียหายแค่ไหน ใช้อธิบายอาจารย์ว่าทำไมต้องเปลี่ยนห่วงตะขอ

## อ่านก่อนเริ่ม
- `sim/drop_fe.py`: FE แบบ voxel บนไฟล์ STL จริง ทำหน้าที่ 3 อย่าง
  - หาความแข็งโครงสร้างและความเค้นต่อแรง 1 N ตรงจุดชน
  - หาแรงสูงสุดด้วยสมดุลพลังงาน: มวลเทียบเท่า, ความแข็งโครงสร้าง และการยุบตรงจุดสัมผัสแบบ Hertz ที่มีเพดานจากความแข็งผิว (plastic)
  - เลือกกำลังวัสดุตามทิศความเค้น: ในระนาบชั้นพิมพ์ หรือขวางชั้น
- `sim/drop-fe-results.json`: ผล FE ของแบบปัจจุบัน 5 จุดชน คือ ห่วงตรงลง, ห่วงเฉียง, มุมฝาหลัง, มุมฝาหน้า และขอบข้าง
  - `fe.compliance_E1`: ความยืดหยุ่นเมื่อ E = 1 (ความแข็ง = E / compliance)
  - `fe.s1_perN`: ความเค้นดึงสูงสุดต่อแรง 1 N (Pa/N)
  - `fe.vz`: ทิศความเค้นเทียบแกน z ใช้เลือกกำลังวัสดุ
  - `fe.hot`: จุดความเค้นสูงสุด อยู่ในพิกัดไฟล์ STL
  - `fe.P_stl` / `fe.n_stl`: จุดชนและทิศแรง
- `sim/drop-sim.mjs`: ส่วนสุ่มท่าตกและแยกว่าส่วนไหนแตะพื้นก่อน (โอกาส: มุม 52%, ห่วง 34%, ขอบ 13%, หน้า 1%) ใช้เฉพาะส่วนนี้ เพราะส่วนคำนวณความเค้นในไฟล์นี้เกินจริงไปแล้ว
- STL ใน `print/v2/`: `v2-front-shell.stl` และ `v2-back-shell-pendant.stl`
  - **การแปลงพิกัด** STL เป็นท่าวางพิมพ์ ต้องแปลงเป็นพิกัดโมเดลก่อน
    - ฝาหลัง: `model = (x, y + 3.25, z − 10.75)`
    - ฝาหน้า: `model = (x, −y, 10.75 − z)`
  - **ประกอบในพิกัดโมเดล** ฝาหน้าอยู่ z 0..10.75 ฝาหลังอยู่ z −10.75..0
- Skill: `threejs-fundamentals`, `threejs-animation`, `threejs-interaction`, `threejs-geometry` ใน `.agents/skills` โปรเจกต์ใช้ three **0.180** ผ่าน importmap ของ jsDelivr แบบเดียวกับ `work/build.mjs` ใช้เฉพาะ API ที่มีใน r180

## สิ่งที่ต้องทำ
1. **`sim/drop-model.mjs`:** ES module ที่ทั้งหน้าเว็บและเทสต์ใช้ร่วมกัน
   - **พอร์ตจาก `drop_fe.py` เป็น JS:** ฟังก์ชัน `mEff`, `contact`, `peakForce` และการเลือกกำลังวัสดุ ใช้ค่าวัสดุ PLA/PETG ชุดเดียวกับในไฟล์ Python
   - **`assess(design, featureId, material, heightM)`:** คืนค่า `{F, g, dent, s1, limit, ratio, level, hot}`
   - **ระดับความเสียหาย (`level`):**
     - `ratio ≥ 1` คือ "ร้าว" (PLA) หรือ "ร้าว/งอ" (PETG)
     - `ratio ≥ 0.7` หรือ `dent > 0.3 มม.` คือ "บุบ/ขาว"
     - `dent > 0.05` คือ "รอยเล็กน้อย"
     - นอกจากนั้นคือ "ไม่เสียหาย"
   - **จุดชนที่ไม่มีใน FE:** เช่น หน้าราบ ให้ใช้ค่าประมาณที่บอกในหน้าว่า "ค่าประมาณ ไม่ได้คำนวณ FE"
2. **`sim/build-drop-live.mjs` สร้าง `sim/drop-live.html`:** เปิดจากไฟล์ได้โดยไม่ต้องมี server
   - **ฝังข้อมูลลงหน้า:** STL ฝาหน้าและฝาหลัง (base64), `drop-fe-results.json` และ `drop-model.mjs` (inline)
   - **รองรับหลายแบบกล่อง:** อ่านรายการแบบจาก `sim/drop-designs.json` ที่ต้องสร้างใหม่
     - ตอนนี้มีแบบเดียว คือ `current` = ห่วงยื่น
     - Claude จะเพิ่มแบบ `lug` (แท่งเกี่ยวในแผ่นหัว) เข้ามาเองหลังจากนี้ แต่ละแบบระบุไฟล์ STL, ไฟล์ผล FE และตารางแมปจุดแตะพื้นไปยังจุดชนใน FE
     - ถ้ามีหลายแบบ ให้หน้ามีปุ่มเลือกแบบ
3. **ฟิสิกส์การตกในหน้าเว็บ (สดในเบราว์เซอร์):**
   - **ตัวกล่อง:** เป็นวัตถุแข็งชิ้นเดียว มวล 59 กรัม ใช้ inertia จากกล่อง 40 × 98 × 21.5 มม. จุดศูนย์ถ่วงอยู่ที่ z −2.5 มม.
   - **จุดชนพื้น:** ได้จาก convex hull ของ STL ทั้งสองฝาในพิกัดโมเดล ลดเหลือประมาณ 150–300 จุด แต่ละจุดติดป้ายชนิดด้วยกติกาเดียวกับ `classify` ใน `drop-sim.mjs`: ห่วง, มุม, ขอบ, หน้า
   - **การสัมผัสพื้น:** ใช้แบบ penalty มีหน่วงและแรงเสียดทาน คำนวณด้วย semi-implicit Euler แบบ substep ให้เสถียร
   - **ปรับได้:** ความสูง 0.3–2.0 ม. (ค่าเริ่มต้น 1.3), วัสดุ PLA/PETG, ท่าเริ่ม (สุ่ม / ห่วงลง / มุมลง / ขอบลง / หน้าราบ) และความเร็วหมุนสุ่มเล็กน้อย
   - **ตอนแตะพื้นครั้งแรก:**
     - หาจุด hull ที่ชน แล้วเรียก `assess` ด้วยจุดชนจริงและทิศปกติของพื้น (ใช้คำนวณ `mEff` ใหม่ ไม่ใช้ค่าตายตัว)
     - หยุดภาพแบบสโลว์โมชัน 1/20 เท่าราว 1 วินาที
     - ส่องไฟแดงที่จุด `hot` ของจุดชนนั้น
     - ถ้าระดับเป็น "ร้าว" ให้วาดเส้นร้าวสั้นๆ ที่จุดนั้น
   - **หลังตกครั้งแรก:** ปล่อยให้เด้งต่อจนนิ่ง การชนครั้งต่อไปให้ประเมินด้วยความเร็วจริงตอนชน และเก็บระดับที่แย่ที่สุด
4. **แผงผล (ภาษาไทย):**
   - ความเร็วตอนชน
   - ส่วนที่แตะพื้นก่อน
   - แรงสูงสุด (N)
   - g
   - ความลึกรอยบุบ
   - ความเค้นเทียบกำลัง (เป็น % พร้อมแถบสี)
   - ระดับความเสียหาย
   - หมายเหตุว่าเป็นโมเดลอย่างง่าย ค่าวัสดุทั่วไป ไม่ได้ทดสอบจริง และบอกว่าใช้กำลังในระนาบชั้นพิมพ์หรือขวางชั้น
5. **ปุ่ม "สุ่มตก 1,000 ครั้ง":**
   - ไม่ต้องแสดงภาพ ให้สุ่มท่าแล้วคำนวณเร็วๆ จากจุดที่แตะพื้นก่อนกับ `assess`
   - แสดงกราฟแท่ง: % ไม่เสียหาย / รอย / บุบ / ร้าว และ % ที่แต่ละส่วนแตะพื้นก่อน
   - ถ้ามีหลายแบบ ให้มีโหมดเทียบสองแบบข้างกัน
6. **มุมกล้องและการแสดงผล:**
   - มี OrbitControls พื้นมีกริด 10 มม. และเงา
   - เคารพ `prefers-reduced-motion` (เริ่มแบบหยุด กดเล่นเอง)
   - ใช้ได้บนจอ 390 px

## ข้อจำกัด
- **ไฟล์ที่ทำได้:** ทำเฉพาะใน `sim/` ได้แก่ `drop-model.mjs`, `build-drop-live.mjs`, `drop-live.html`, `drop-designs.json` และ `test-drop-live.mjs`
- **ห้ามแตะ:** `work/`, `print/` และ `outputs/` เพราะ Codex อีกตัวกำลังแก้แบบฝาหลังอยู่ ให้อ่าน STL ได้อย่างเดียว ห้ามแก้ `sim/pendant-clips.json` และต้นฉบับใน Documents
- **การเขียนไฟล์:** เขียนเป็น UTF-8 เท่านั้น ห้ามใช้ Set-Content/Get-Content ของ PowerShell แก้ไฟล์
- **ภาษา:** ข้อความบนหน้าเป็นภาษาไทย

## เกณฑ์ว่าเสร็จ
- `node sim/test-drop-live.mjs` จาก `case3d/` ผ่าน ต้องตรวจครบ 5 ข้อ

  2. การแยกส่วนที่แตะพื้นก่อน (สุ่ม 20,000 ครั้ง) ได้สัดส่วนใกล้ค่าใน `drop-sim.mjs` ไม่เกิน ±2%
  3. ฟิสิกส์: ปล่อยจาก 1 ม. ความเร็วตอนชนต่างจาก √(2gh) ไม่เกิน 3% และสุดท้ายกล่องนิ่งบนพื้นโดยไม่จมพื้นเกิน 0.5 มม.
