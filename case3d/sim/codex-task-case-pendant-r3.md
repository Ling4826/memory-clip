## 2. ตำแหน่งกล้องและการ์ด SD (ค่าใหม่ ต่างจากแบบเดิม)
- **ทุกอย่างอยู่ปลายเดียวกัน:** หัว USB-C ของ XIAO, ขั้วต่อสายแพกล้องสีขาว และการ์ด SD อยู่ปลายเดียวกัน (ขอบฝั่ง USB, y− ในพิกัดบอร์ด)
- **เลนส์อยู่กลางแนวกว้าง:** วัดถึงขอบซ้ายกับขอบขวาได้ 8.5 / 8.5 ให้ `camera.x = 0` (เดิม −3)
- **กลางเลนส์ห่างขอบฝั่ง USB 14.2 มม.** ตามแนวยาว ในพิกัดที่กลาง PCB = (0,0) และบอร์ดยาว 21 จะได้ `camera.y = 14.2 − 10.5 = 3.7` (เดิม 3) ถ้าพิกัดใน config ไม่ได้อ้างอิงแบบนี้ ให้แปลงให้ถูก แล้วเขียนวิธีแปลงไว้ในคอมเมนต์
- **ขอบกล่องกล้องฝั่งไกลอยู่ที่ 19.1 มม.** จากขอบฝั่ง USB ใช้ตรวจว่ากล้องไม่ชนผนัง
- **ความยาวรวม 24.8 มม.** นับรวมบอร์ด กล้อง และการ์ด SD ที่เสียบสุด แปลว่าการ์ดยื่นเลยขอบ PCB ฝั่ง USB ประมาณ 4 มม.
  - ตรวจว่า model การ์ด SD และผนังกันการ์ด (`v2.sdStop`) ตรงกับค่านี้
  - ระยะจากปลายการ์ดถึงผนังกันการ์ดต้องเท่ากับความหนาโฟม (2.0)
  - ถ้าการ์ดใน model ยื่นไม่ถึง 4 มม. หรือยื่นเกิน ให้แก้ให้ตรง
- **ช่องรับภาพบนฝาหน้า:** ย้ายให้ตรงเลนส์ตำแหน่งใหม่ และต้องไม่บังมุมมองภาพ (FOV) ของเลนส์ Ø8 ที่ก้ม 12°
